# Fleet Commander

Système complet de gestion de flotte de véhicules.

## Fonctionnalités
- Gestion des véhicules, chauffeurs et réservations
- Suivi de la maintenance et des pannes (incidents)
- Gestion du carburant et des inspections journalières
- Intégration complète avec Supabase (PostgreSQL)

## Lancement en local
```bash
npm install
npm run dev
```

## Compilation pour la production
```bash
npm run build
```
